## 3. THE RESIDUAL ORPHAN CLASS (explicitly NOT cured — keep this visible)

`ratatui_ruby` 1.5.0's `poll_event` passes NO unblock-function
(`ext/ratatui_ruby/src/events.rs:391-396`, UBF `None` at :394). On a dead/closed
pty the poller thread hot-reads the dead fd at ~100% CPU and never returns to
Ruby; `Thread#kill` cannot recover it, and while the wedge holds ordinary signals
go undelivered process-wide. I75's cure covers every case in which a thread can
still be scheduled — in-band routing plus a main-thread `exit!(code)` bypasses
MRI's `rb_ec_cleanup` thread join and kills the process promptly with the mapped
code on the raw wire. **The nobody-alive-to-exit orphan (trap context unreachable)
still requires an external SIGKILL until the upstream UBF fix lands.** That is the
one live carve-out from "the orphan class is cured", and it is stated in the I75
verdict and ARCHITECT.md row 15.
